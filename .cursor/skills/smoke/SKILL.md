# Прогон золотого пути

Скриншот — не доказательство. Кликай сам, читай консоль и сеть.

## Подготовка

Сервер на `http://localhost:3000`. Проверь, что он жив, и не поднимай второй:

```bash
lsof -i :3000 -sTCP:LISTEN 2>/dev/null || echo "нет сервера"
```

Логи dev-сервера лежат в файле терминала — читай их после каждого шага, там видны 500-е и ошибки RPC.

Мобильный приоритет: viewport **390×844**. Ошибки консоли и `pageerror` собирай с самого начала, а не в конце.

## Шаги

Веди этот список и отмечай по ходу:

```
- [ ] 1. Гость: / открывается, «Загрузка…» уходит < 3 с
- [ ] 2. Инвайт-попап: /?ref=COBRA-5429 → аватар, имя, таймер, 300 ₽
- [ ] 3. «Забрать бонус» → /login?invite=...&bonus=300, код лежит в localStorage
- [ ] 4. «Позже» и «Это не мой инвайт» реально закрывают и сбрасывают
- [ ] 5. Тренер: карточка открывается, сплит виден, цена честная
- [ ] 6. Оплата: создаётся платёж (на локале — mock, на проде mock обязан быть 403)
- [ ] 7. Check-in: Таланты начисляются РОВНО один раз при двойном клике
- [ ] 8. Донат «Поддержать бойца»: шит открывается, сумма и цель совпадают с карточкой
- [ ] 9. Табы feed / passport / leaderboard переключаются
- [ ] 10. 390px: нет горизонтального скролла, золотая CTA не перекрыта
```

## Что считать блокером

- Белый экран, вечная «Загрузка…», ошибка в консоли на золотом пути.
- 401 или 500 там, где гость должен видеть понятный экран входа.
- Двойное начисление Талантов или денег при двойном клике. Это P0 всегда.
- Кнопка есть, но ничего не делает — хуже, чем отсутствие кнопки.
- Цифры расходятся между экранами (сбор на карточке ≠ сбор в донате).

Не блокер за сутки до запуска: кривой отступ, не идеальный шрифт, предупреждение линтера.

## Проверка идемпотентности

Обязательно жми «оплатить» и «check-in» дважды подряд, быстро. Начислиться должно один раз. Если дважды — останавливайся и зови субагента `economy-guard`.

```
Проверено вживую:

```
