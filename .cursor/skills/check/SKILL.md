# Отметить галочку в чеклисте

## Правило номер один

`[x]` ставится только за проверенное вживую. «Есть в коде» — это не проверено. Если проверки не было — сначала скилл `smoke`, потом галочка.

## Шаги

1. Найди пункт в `LAUNCH-CHECKLIST.md`. Секции: `🔴 CRITICAL`, `🟡 IMPORTANT`, `🟢 CAN WAIT`.
2. Замени `- [ ]` на `- [x]` в этой строке. Формулировку пункта не переписывай.
3. Если суть изменилась, добавь в конец строки короткое уточнение в скобках, как здесь:
   `- [x] Кнопка «Забрать бонус» редиректит на регистрацию (было /booking → теперь /login)`
4. Ничего больше в файле не двигай: ни порядок, ни пустые пункты.
5. Коммить **только** чеклист:

```bash
git add LAUNCH-CHECKLIST.md && git commit -m "Tick <короткое описание> in launch checklist"
```

Код в этот коммит не попадает. Владелец коммитит код сам, когда попросит.

## Если пункта нет

Добавь его в подходящую секцию тем же стилем — короткая строка, по-русски, с проверяемым условием. «Работает авторизация» проверить нельзя. «Вход через Telegram Mini App доходит до паспорта» — можно.

## Если проверка провалилась

Галочку не ставь. Скажи прямо, что именно не работает, и в какой секции пункт остаётся открытым.

## Отчёт

Одна строка: что отметил, что осталось красным в `CRITICAL`, и номер коммита.
